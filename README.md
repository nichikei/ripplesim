# 🌊 RippleSim

**Drop a piece of news into a virtual society — watch the ripples of public opinion spread.**

RippleSim is a multi-agent social simulation engine. Given a seed event (a news headline,
a policy draft, a product launch), it generates a population of AI agents with distinct
personalities, connects them in a realistic social network, and simulates how opinions
form, spread, and polarize over time. At the end it produces a prediction report.

> Status: work in progress 🚧

## Planned features

- [ ] Persona generator — agents with archetypes, conviction, sociability
- [ ] Scale-free social network (preferential attachment)
- [ ] Opinion dynamics engine (bounded-confidence model)
- [ ] Post/feed content generation
- [ ] Event injection mid-simulation ("god mode")
- [ ] Prediction report generator
- [ ] REST API (FastAPI) + web dashboard
- [ ] Optional LLM-generated post content
